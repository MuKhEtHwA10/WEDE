# WEDE
The Kaya Home & Living website was developed using HTML5, CSS3, and JavaScript, forming the foundational triad of front-end web development. HTML5 provides the structural framework of every page, using the `<!DOCTYPE html>` declaration to inform the browser that the document is HTML5, followed by the `<html lang="en">` root element that specifies English as the document language. The `<head>` section contains essential metadata including the character encoding (`<meta charset="UTF-8">`) and viewport settings (`<meta name="viewport" content="width=device-width, initial-scale=1">`) for mobile responsiveness. Semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` are used to structure content meaningfully, while tags delimit the start and end of elements. Start tags follow a specific format: a "<" character, the element's tag name, optional attributes separated by spaces, and a ">" character. Void elements such as `<img>`, `<input>`, and `<br>` have only a start tag with no end tag, as specified by W3C guidelines. CSS (Cascading Style Sheets) is used to describe how HTML elements are displayed, allowing fine control over formatting, layout, colours, backgrounds, font sizes, and positioning. The external stylesheet is linked via the `<link>` tag, which offers several benefits: authors and site managers can share style sheets across multiple documents, changes can be made without modifying individual HTML documents, and user agents can load style sheets selectively based on media descriptions. A CSS rule consists of a selector and a declaration block — the selector points to the HTML element to style (e.g., `h1`), while the declaration block contains one or more declarations separated by semicolons. The code uses multiple selector types including element selectors (e.g., `body`, `h1`), class selectors (e.g., `.product-card`, `.hero-btn`), and ID selectors (e.g., `#toast`). When different styles are specified for HTML elements, the styles cascade with the following priority: inline styles (highest), internal and external style sheets, then browser defaults. The code employs a mobile-first responsive design approach using media queries (e.g., `@media (max-width: 700px)`) to adapt layouts for different screen sizes, with breakpoints selected based on content rather than specific devices. Relative units such as `rem` (relative to the root element's font size) and `vh`/`vw` (viewport height/width) are used for better scalability than fixed pixel values, while colour values use HEX notation (e.g., `#c1663d`) for precise colour specification. JavaScript is used to add behaviour and interactivity to the web pages, allowing validation of form data, drag-and-drop functionality, changing styles on the fly, animating page elements, and handling button functionality. The Document Object Model (DOM) is a structured tree representation of the HTML of a web page that allows programmatic access to the document structure, accessed through methods such as `document.getElementById('id')` and `document.querySelectorAll(selector)`. The code uses `element.innerHTML` to update HTML content and `element.textContent` to update text content. Event-driven programming is employed, where the program's behaviour is based on events, using the `element.addEventListener(event, function)` method to associate callback functions with events, as well as inline `onclick` handlers to trigger JavaScript functions when buttons are clicked. Local storage is used as a browser mechanism for storing data client-side that persists across browser sessions, with data stored as key/value pairs where both must be strings. The code uses `localStorage.setItem("key_name", "value")`, `localStorage.getItem("key_name")`, `JSON.stringify(myObject)` to convert objects to JSON strings for storage, and `JSON.parse(jsonString)` to convert JSON strings back to objects, enabling the shopping cart to persist items even when the user navigates between pages or closes the browser. Timers are used via `setTimeout(function, milliseconds)` to execute a function after a specified delay, used for the toast notification that disappears after 2.5 seconds.
